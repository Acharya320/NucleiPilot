# Test Results — NucleiPilot (Part 2)

*Start here. This folder is the **evidence from the sandbox runs**: what the agent discovered, the
decisions it took, and the raw artifacts behind both. Everything here was generated by the scripts in
[`../../scripts/`](../../scripts/) against a localhost toy app and a local Grafana 8.3.0 container —
**localhost-only, read-only**. For what this evidence can and cannot prove, see
[`../../docs/toy_spec.md`](../../docs/toy_spec.md) §7; for the honest evaluation, see
[`../../docs/analysis.md`](../../docs/analysis.md).*

**If you read one thing, read this page.** Then: `summary.md` for the data, and open one file in
`traces/` (with `python scripts/show_trace.py <file>`) to watch the agent decide step by step.

---

## 1. What the agent discovered / accomplished

| Run | Target | Outcome |
|---|---|---|
| **Toy app**, budget 2 | localhost 5-endpoint app | Confirmed the two **business-critical** issues — `/payments` (admin, no auth) and `/account` (PII/secret leak); **rejected** the `/health` false-positive trap on evidence. |
| **Grafana 8.3.0** | local container | Reasoned detected version → **applicable CVE-2021-43798**; confirmed arbitrary file read **read-only** (planted marker + `/etc/passwd`). |
| **Safety** | — | All four misuse cases **failed safe** (out-of-scope, invented id, malformed model output, over-budget). |

## 2. The decisions it took (four planners, same budget 2)

Every scan was **proposed by a planner and authorized in code** before it ran. The honest headline:

| Planner | Confirmed at budget 2 | Note |
|---|---|---|
| A — fixed (ceiling) | `/payments`, `/account`, `/docs` | runs everything; the reference, not a competitor |
| B1 — severity rule | `/docs` only | chased the high-severity trap; **missed both business-critical issues** |
| B2 — context rule | `/payments`, `/account` | the strong non-LLM baseline |
| **C — LLM** | `/payments`, `/account` | **ties B2 on outcome** (same findings every run; pick-*order* varies — LLM nondeterminism) |

Full step-by-step decision logs are in [`traces/`](traces/) — render any one with
`python scripts/show_trace.py results/final/traces/e1_C_run0.json` to see
*propose → authorize → act → verdict*.

## 3. What we claim — with evidence

| # | Claim | Result | Evidence file |
|---|---|---|---|
| 1 | **A bounded, auditable loop** — model proposes, *code* authorizes every scan (scope + catalog + budget), with a full trace. | Out-of-scope target, invented template id, malformed LLM JSON, and over-budget proposals all **fail safe**. | `safety_checks.md`; `traces/*.json` |
| 2 | **Evidence-based verdicts** — a fired template is a hint, not a finding; false positives are rejected *on evidence*. | `/docs` and `/health` send the **identical** debug indicator; only the validation's content signature separates them → `/docs` **CONFIRMED**, `/health` **NOT_CONFIRMED**. | `e3_trap.json`; `summary.md` (E3) |
| 3 | **Business-aware prioritization under a tight budget.** | Severity-only **B1** missed the business-critical `/payments` + `/account` and wasted a slot on the trap; context-aware **B2** and the LLM **C** both confirmed them. | `summary.md` (E1); `comparison.csv` |
| 4 | **Decisions follow business context**, not a fixed favorite. | Flip `/payments`↔`/docs` importance (responses unchanged): **B2 and C both shift** their first pick to `/docs`. | `summary.md` (E2) |
| 5 | **The LLM reliably matches the strong rule** (the honest headline). | Across **3 runs** C confirmed the **same findings as B2** (`/payments` + `/account`) every run; the validation *order* varied run-to-run (expected LLM nondeterminism) but the outcome did not. This is *not* "the LLM beats rules." | `summary.md` (E1) |
| 6 | **The same engine generalizes to a real app** — a new target is just another registry + catalog entry. | Local Grafana 8.3.0: the LLM reasoned version → **applicable CVE-2021-43798** over the 2020-13379 distractor with **0 CVE-specific code**; planted-marker read **CONFIRMED** (+ `/etc/passwd` **CONFIRMED**). | `grafana_demo.json` (E4); `e6_generalization_note.md` (E6) |

### What we do NOT claim (equally important)
- **Not** that the LLM beats a well-tuned rule here. On a small, fully-labeled toy a few lines of
  context-aware rule (B2) tie it — a property of the toy's size, not a weakness of the agent (§7).
- **Not** real-world reliability. Whether LLM reasoning beats rules on messy, unlabeled, real targets
  is exactly what the 90-day pilot in [`../../docs/build_decision.md`](../../docs/build_decision.md) is built to measure.
- **Not** improved *detection*. Nuclei already detects; the agent helps *choose and triage*, under control.
- All testing was **localhost-only and read-only**, against systems we control or a throwaway container.

## Reproduce (each is one command from the repo root)

```
python -m unittest discover -s tests            # 37 deterministic tests (no Nuclei/API)
python scripts/smoke_toyapp.py                  # the toy app serves the exact signatures
python scripts/run_experiment.py                # E1/E2/E3 -> this folder (needs Nuclei; LLM key for C)
python scripts/safety_checks.py                 # E5 fail-safe demonstrations (no deps)
python scripts/run_grafana.py                   # E4 real-app demo (needs Docker + Nuclei + LLM key)
```

Everything regenerates into this folder. See the repo [`../../README.md`](../../README.md) for full setup
(both Windows and macOS/Linux).
